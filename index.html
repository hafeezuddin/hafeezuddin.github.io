about

Building the Data
Foundation

Analytics engineer with deep expertise across the modern data stack — from ingesting raw data via Azure Data Factory to delivering polished Power BI dashboards that non-technical stakeholders can actually use.

Core speciality is designing and implementing Medallion Architecture (Bronze → Silver → Gold) on Databricks with Delta Lake — building reliable, scalable lakehouse pipelines that separate raw ingestion, cleansing, and business-ready aggregation into clean, independently testable layers.

Proficient in PySpark, Python & Pandas for large-scale transformations on Databricks, paired with Advanced SQL for semantic modelling and dimensional design. Fluent in both ETL and ELT paradigms across the Azure and Microsoft Fabric ecosystems.
